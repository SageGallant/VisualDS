### **Prompt 1: User Login and Authentication**

**Level-0**:  
- **External Entity**: User  
- **Process**: "Login"  
- **Data Stores**: User Data (Database containing User credentials)  
- **Data Flow**: User credentials → "Login" → User Data → authentication response → User

**Level-1**:  
- **Process**: "Login Process"  
  - **Sub-processes**:  
    1. "Validate User Credentials"
    2. "Authenticate User"  
- **External Entity**: User  
- **Data Stores**: User Data (Credentials)  
- **Data Flow**: User credentials → "Validate User Credentials" → User Data → "Authenticate User" → Authentication response

**Level-2**:  
- **Sub-process 1 - Validate User Credentials**:  
  - Input: User Credentials (Username, Password)  
  - Output: Credentials validation result (True/False)  
  - Data Store: User Data (Stores hashed passwords)  
- **Sub-process 2 - Authenticate User**:  
  - Input: Valid credentials from previous sub-process  
  - Output: Authentication result (Success or Failure)  
  - Data Store: User Data (Stores user details and roles)

### **Prompt 2: View Data Structure Information**

**Level-0**:  
- **External Entity**: User  
- **Process**: "View Data Structure"  
- **Data Stores**: Data Structure Data (Contains list of all data structures, descriptions)  
- **Data Flow**: User request → "View Data Structure" → Data Structure Data → Data Structure details → User

**Level-1**:  
- **Process**: "Display Data Structure Information"  
  - **Sub-processes**:  
    1. "Fetch Data Structure Data"  
    2. "Display Description and Theory"  
    3. "Fetch Visualization Data"  
- **External Entity**: User  
- **Data Stores**: Data Structure Data, Theory Data, Visualization Data  
- **Data Flow**: User request → "Fetch Data Structure Data" → Data Structure Data → Theory Data → "Display Description and Theory" → Visualization Data → "Fetch Visualization Data" → Data Structure Information → User

**Level-2**:  
- **Sub-process 1 - Fetch Data Structure Data**:  
  - Input: Data Structure ID from User request  
  - Output: Data structure details (name, description)  
  - Data Store: Data Structure Data (Stores descriptions of each data structure)  
- **Sub-process 2 - Display Description and Theory**:  
  - Input: Data structure details  
  - Output: Displayed description and theory content  
  - Data Store: Theory Data (Stores theoretical content for each data structure)  
- **Sub-process 3 - Fetch Visualization Data**:  
  - Input: Data structure ID  
  - Output: Graphical representation or visualization  
  - Data Store: Visualization Data (Stores graphical content for each data structure)
